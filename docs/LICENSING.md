# Decisão de licenciamento

## Código original do projeto

A primeira versão do `ai-harness` usa a licença MIT. É uma licença permissiva
curta que permite usar, copiar, modificar, distribuir, sublicenciar e vender
o código, desde que os avisos de copyright e de licença sejam preservados.
Também declara que o software é fornecido sem garantia. Ela não contém uma
concessão expressa de patentes como a Apache-2.0.

A opção MIT mantém baixo o atrito para integrar este pacote independente a
aplicações Python de diferentes tipos. O aviso usa “ai-harness contributors”
como titular coletivo inicial; os contribuidores devem verificar que têm
direito de licenciar suas contribuições sob estes termos.

## Componentes de terceiros

A licença MIT deste repositório cobre somente o código original aqui
licenciado. Ela não relicencia Pydantic, pytest, futuros provedores, modelos,
serviços externos ou qualquer outro componente de terceiros. Cada componente
mantém seus próprios termos; antes de distribuir uma aplicação, seus
responsáveis devem verificar as licenças aplicáveis e as condições dos
modelos e serviços utilizados.

Esta documentação registra a escolha de engenharia do projeto e não é
aconselhamento jurídico.
